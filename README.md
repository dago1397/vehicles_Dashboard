# vehicles_Dashboard

Proyecto Sprint 7 TripleTen

Aplicación web desarrollada con Streamlit para explorar un conjunto de datos de anuncios de venta de coches usados en EE. UU.

La aplicación permite visualizar una vista previa de los datos y generar, mediante casillas de verificación, un histograma de la distribución del odómetro y un gráfico de dispersión que relaciona el odómetro con el precio.

Tecnologías: Python, pandas, Plotly y Streamlit. Desplegada en Render.

**Aplicación desplegada:** https://vehicles-dashboard-0fhc.onrender.com
